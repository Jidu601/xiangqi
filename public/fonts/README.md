# 书法字体

来源：Google Fonts 官方仓库 `google/fonts/ofl/mashanzheng`，Ma Shan Zheng，SIL Open Font License 1.1，许可证见 `OFL.txt`。

实际使用 `brush.woff2`：仅保留本项目界面、棋子与技能文字所需字符，并将内部字体名称改为 `ChuHe Ink Brush`。字符来源是 `app.js`、`engine.js`、`effects.js` 和 `index.html`。原始字体仅用于生成子集，不随生产网页加载。

`pieces.woff` 为 Google Fonts 官方提供的 Noto Serif SC 600 字重子集，只含“帅仕相马車炮兵将士象卒”，约 5KB，许可证见 `NotoSerifSC-OFL.txt`。红黑双方的车均使用传统棋面字“車”。棋盘、头像、复活选择与复活演出的棋子统一使用此字体；标题与技能名称保留书法字体。
